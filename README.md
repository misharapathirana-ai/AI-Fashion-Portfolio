# Fashion Data Analytics & Prediction

## Overview

An exploratory data analysis and machine learning project focused on understanding fashion product trends, pricing, customer ratings, and consumer preferences.

## Objectives

- Explore and clean fashion-related data
- Identify important fashion market trends
- Analyze relationships between price, category, and ratings
- Build machine learning models
- Develop an interactive analytics dashboard

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Plotly
- Streamlit
- Jupyter Notebook
